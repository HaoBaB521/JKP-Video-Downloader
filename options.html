全新更新 · Release Notes
v2.3 · D站伐浩
⚡
功能 NEW
不管在作者主页、你的主页、点赞、收藏还是历史记录里，只要视频上有下载图标，基本都能一键下载，很少报错，实际速度主要看你的网络环境。
🚀
Performance NEW
重新优化了视频解析方法，可以更快读取当前视频的直链，点开几乎就能下载，响应比旧版本明显更快。是否流畅还取决于浏览器反应和网络支持。
🛡️
Stability NEW
修复了偶尔卡顿、卡住、白屏、点击后长时间无反应等问题，现在稳定很多，几乎都能正常下载，除非浏览器本身反应很慢。
📁
文件名 File Name
支持「主要生成 / 2号生成」两套文件名逻辑，自动读取作者、描述、话题、清晰度、视频 ID，并过滤非法字符，文件名更安全规范。
✨
全新 UI NEW
采用苹果同款液态玻璃质感与磨砂效果，下载按钮改为全透明样式，整体更通透清爽，告别以前沉闷的纯黑界面。
