## 安装教程
1. 下载本仓库 ZIP（Code → Download ZIP）并解压；
2. 打开 Chrome / Edge，进入扩展管理页（`chrome://extensions` 或 `edge://extensions`）；
3. 打开右上角「开发者模式」；
4. 点击「加载已解压的扩展程序」，选择解压出的文件夹 `JKP（专注于视频下载）_2.2`；
5. 打开抖音网页版，刷新页面即可使用。

## 主要功能

- ✅ 全新 UI：Dashboard 管理后台风格设置页、全透明下载按钮
- ✅ 首页推荐流卡片一键下载（v2.2 新增）
- ✅ 解析与下载并行：有播放地址立即下载，不再互相阻塞（v2.2 优化）
- ✅ 双重解析引擎：主要生成 / 2号生成 两种文件名生成逻辑，自动兜底，解析更稳
- ✅ 解析提速：并行解析 + 30 秒缓存，点击即出
- ✅ 免水印下载抖音视频
- ✅ 文件名自定义：作者 / 描述 / 分辨率 / 视频 ID
- ✅ 视频质量可选：最高分辨率 / 最高码率 / 最大文件
- ✅ 下载子目录设置
- ✅ 版本说明面板
